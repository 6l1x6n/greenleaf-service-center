# ТЗ (техническое задание) — сайт Greenleaf

## Архитектура

- **Сайт**: статик-ассеты в `public/` + Cloudflare Worker (`worker.js`, имя `mygreenleaf`).
- **Деплой**: только через git push — `.github/workflows/deploy.yml` (секрет `CF_API_TOKEN`).
  Ручной `wrangler deploy` из устаревшей копии перезатирается авто-деплоем по пушам.
- **Парсер каталога**: `scripts/parser/parser.py`, GitHub Actions (`parse-catalog.yml`).
  4 запуска в день (Астана): 11:00, 14:00, 17:00, 20:00. Все запуски «умные»:
  существующие товары — только количества по артикулам, новые артикулы создаются
  с полными данными один раз (в любом запуске). Полный прогон — `--full` (ручной).
  Учётка портала s240534, партнёр kz44326234.
- **Заказы**: KV `orders` (new/confirmed/cancelled) + `orders_history` (архив суперадмина).
  Доступно онлайн = факт(парсер) − 2-мин холды − Σ new − Σ confirmed после последнего синка.
  Подтверждение: резерв → продажа (остаток не меняется); после синка парсера заказ
  архивируется и не влияет на остаток. Отмена возвращает товар; удаление confirmed не возвращает.
- **Данные**: публичный каталог `public/data/products.base.json` (виртуальный
  `/data/products.json` с оверрайдами суперадмина), остатки `store-stock.json`,
  карточки СЦ и заказы в Cloudflare KV (`SC_STORES`).
- **Кабинет**: вход только для СЦ и суперадмина. СЦ меняет свой пароль (логин — нет),
  может задать новый пароль портала, но не видит текущий. Пароль портала видит только
  суперадмин; сброс пароля — только суперадмин (кнопка в карточке СЦ).
  Email владельца и флоу «Забыли пароль» удалены.
- **Безопасность**: пароли (портала, кабинетов, admin_creds, заявок) в KV зашифрованы
  AES-GCM (Worker-секрет `DATA_ENC_KEY`, формат `enc:v1:<iv>:<ct>`). Расшифровка — только
  для входа, панели суперадмина и `/api/parser-config` (по API-ключу). СЦ пароли не видны.
- **Секреты** (вне репозитория):
  - Cloudflare Worker secrets: `TG_BOT_TOKEN`, `TG_CHAT_ID`, `TG_ORDERS_CHAT_ID`, `STORE_CREDS`, `AUTH_HMAC_KEY`, `PARSER_API_KEY`
  - GitHub Actions secrets: `SC_LOGIN`, `SC_PASSWORD`, `CF_API_TOKEN`
  - Локальный `scripts/parser/config.json` — фолбэк для ручного запуска (gitignored)

# ТЗ (техническое задание) — сайт Greenleaf

## Архитектура

- **Сайт**: статик-ассеты в `public/` + Cloudflare Worker (`worker.js`, имя `mygreenleaf`).
- **Парсер каталога**: `scripts/parser/parser.py`, запускается через GitHub Actions (`parse-catalog.yml`, cron раз в 3 ч) под учёткой портала s240534.
- **Данные**: публичный каталог в `public/data/` (`products.json`, `moves.json`, `store-stock.json`), карточки СЦ в Cloudflare KV (`SC_STORES`).
- **Секреты** (вне репозитория):
  - Cloudflare Worker secrets: `TG_BOT_TOKEN`, `TG_CHAT_ID`, `TG_ORDERS_CHAT_ID`, `STORE_CREDS`, `AUTH_HMAC_KEY`, `PARSER_API_KEY`, `RESEND_API_KEY`, `RESEND_FROM`
  - GitHub Actions secrets: `SC_LOGIN`, `SC_PASSWORD`
  - Локальный `scripts/parser/config.json` — фолбэк для ручного запуска (gitignored)
